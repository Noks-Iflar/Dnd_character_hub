# Иконки Dnd Hub · Хвор, версия 2

Две папки, по одной на тему. Приложение берёт иконку из папки текущей темы: `/ui/icons/${theme}/${name}.png`.

- `dark/` — для тёмной темы. У тёмных предметов (ширма, полка, дверь, дневник, песочные часы) светлая обводка.
- `light/` — для пергамента. У светлых предметов (карта, свиток с пером, письмо, лист персонажа, связка писем) тёмная обводка.
- Остальные иконки в обеих папках одинаковые.
- `name.png` — 256×256. Версии 512×512 из архива в проект не кладём: крупнее 120 px иконки не показываются.

| Файл | Где |
| --- | --- |
| `dm-screen` | Экран мастера |
| `pocket-watch` | Планировщик сессий |
| `journal` | Дневник |
| `bookshelf` | Библиотека |
| `map` | Карта мира |
| `character-sheet` | Открыть лист из файла |
| `signet-ring` | Настройки → Аккаунт |
| `hourglass` | Настройки → Часовой пояс |
| `door` | Настройки → Выйти |
| `quill-scroll` | Забрать правки |
| `sealed-letter` | Отправить партию / загрузить снимок |
| `crossed-swords` | Начать игру |
| `letters-bundle` | История версий |

Живописные иконки ставятся от 32 px. Мелкие значки (нижнее меню, шестерёнка настроек) остаются линейными.
